# Data Model

Sheet utama: SETTINGS, USERS, WEEKS, MATERIALS, ACTIVITIES, SUBMISSIONS, GRADES, COMMENTS, GROUPS, GROUP_MEMBERS, PROJECT_PLANS, ANNOUNCEMENTS, ACTIVITY_LOG serta tabel kompatibilitas diskusi/kuis.

Group set:
- `STUDENT_LED`: 2 mahasiswa.
- `UTS_BLUEPRINT`: 4–5 mahasiswa.
- `UAS_CURRICULUM`: 4–5 mahasiswa.

Aktivitas utama:
- `PRJ_STUDENT_LED`
- `ARTICLE_ANALYSIS`
- `PROGRAM_ANALYSIS`
- `PRJ_UTS_BLUEPRINT`
- `PRJ_UAS_CURRICULUM`
- `PARTICIPATION`
